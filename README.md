# Pasos para usar la página

Para empezar, primero se debe de levantar el contenedor desde docker, y ya con eso se comienza con lo siguiente:
1. Dentro de la carpeta del proyecto (no backend ni frontend) usar el comando '.venv\Scripts\activate'
2. Abrir una pestaña dentro de la carpeta de backend y una dentro de frontend
3. Correr 'npm run dev' desde frontend y correr 'uvicorn main:app --reload --host 0.0.0.0 --port 8080' desde backend
4. Abrir el link 'http://localhost:5173' en el navegador, con eso puede comenzarse a usar la página
